# Visual assets

All SVG files in this directory were authored for Rumbo AU and use the tokens
documented in `DESIGN.md`.

The family includes the route mark and vector wordmark, six status glyphs,
timeline, form-field symbols, empty states, topographic pattern and the
community granted stamp. The SVGs contain `viewBox`, no embedded text nodes and
factual titles/descriptions; UI instances that are redundant with nearby text
are mounted as decorative images.

## Raster hero

Generated with the built-in image generation tool on 2026-07-29. The immutable
source remains under the Codex generated-images store; project exports are:

- `hero-editorial.webp` — 1600 × 800, desktop header.
- `hero-editorial.avif` — 1600 × 800, modern format.
- `hero-editorial-mobile.webp` — 900 × 1200, intentional mobile crop.
- `og-rumbo-au.webp` — 1200 × 630, social preview.

Final prompt: a top-down editorial cut-paper collage of the Pacific route
between Chile and Australia, layered abstract application papers, calendar and
community check mark; warm archival paper, deep ink, eucalyptus, terracotta and
mustard; restrained risograph grain; left-side negative space; no people,
readable text, logos, flags, government marks, aircraft, tourist clichés,
watermarks or fake interfaces.
